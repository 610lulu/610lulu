## 🌸 Selected Work

### Deepscape Reverie
**Digital Heritage · Memory · Interactive Storytelling**

An online exhibition that transforms residents’ oral histories and spatial memories into an explorable digital memory landscape, combining knowledge-graph thinking with dreamlike interactive storytelling.

[View repository](https://github.com/610lulu/Deepscape-Reverie) · [Enter exhibition](https://610lulu.github.io/Deepscape-Reverie/)

### Home Firefly Engine
**Physical Computing · ESP32 · Generative Light**

An interactive lighting engine connecting sensor data, Python state logic and distributed ESP32 light nodes through ESP-NOW — exploring how presence and collective activity can become spatial light behavior.

[View repository](https://github.com/610lulu/Home-Firefly-Engine) · [Open browser preview](https://htmlpreview.github.io/?https://github.com/610lulu/Home-Firefly-Engine/blob/main/web_preview.html)

### Smart Care
**Tangible Interaction · Voice · Connected Care**

A tactile, audio-first connected-care prototype exploring how familiar physical controls, voice interaction and lightweight digital records can support older adults living alone.

[View repository](https://github.com/610lulu/Smart-Care)

### Perlin Noise Generative Art Generator
**Creative Coding · Generative Art · Interactive Systems**

A browser-based generative art tool where thousands of particles move through an evolving Perlin-noise flow field, producing fluid visual traces that can be shaped in real time.

[View repository](https://github.com/610lulu/Perlin-Noise-Generative-Art-Generator) · [Try the generator](https://610lulu.github.io/Perlin-Noise-Generative-Art-Generator/Perlin-Noise-Generative-Art-Generator.html)
